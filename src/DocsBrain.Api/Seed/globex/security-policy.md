# Globex information security policy

## Passwords
Passwords must be at least 14 characters long and must not be reused across systems. A password manager is provided to every employee and its use is mandatory for shared credentials. Passwords are rotated only after a suspected compromise.

## Multi-factor authentication
Multi-factor authentication is mandatory for email, the VPN, the source code platform and all admin consoles. Hardware security keys are preferred. SMS codes are allowed only as a temporary fallback for at most seven days.

## Incident reporting
Any suspected security incident, including lost devices and phishing emails that were opened, must be reported to the security team within 24 hours. Do not try to investigate or delete evidence yourself. The security team will open an incident ticket and coordinate the response.

## Devices
Company laptops use full disk encryption and receive operating system updates automatically within seven days of release. Personal devices may access company email only through the managed mobile application.

## Data classification
Data is classified as public, internal, confidential or restricted. Confidential and restricted data must never be shared through personal accounts or consumer file sharing services. Customer data may be stored only in approved systems inside the European Union.

## Access reviews
Managers review access rights of their team every quarter. Access of departing employees is removed on their last working day.
